# 🛡️ Qorgan (Қорған, «щит»)

**Банк видит перевод, но не видит, что клиенту сейчас диктуют по телефону. Qorgan видит.**

Qorgan соединяет три источника, которые сегодня живут раздельно, в один риск-скор перевода:

1. **Сигнал звонка.** Приложение банка (iOS `CXCallObserver`, Android `TelephonyCallback` + режим аудио для мессенджеров) и оператор связи сообщают только метаданные: идёт звонок, с незнакомым номером, через WhatsApp, 14 минут, номер с признаками подмены.
2. **Поведение в приложении.** Паузы при вводе, исправления, вставленные реквизиты, переключения между банком и звонком: так выглядит человек, которому диктуют.
3. **Разведданные Апа.AI.** ИИ-«апашка» переписывается с мошенниками и вытягивает карты дропов, номера и фишинговые ссылки в общий реестр. Плюс OSINT доменов (RDAP/WHOIS, Certificate Transparency, тайпсквоттинг брендов KZ).

Результат в момент перевода: **пропустить**, **спросить** («Вам сейчас кто-то диктует?»), **задержать на 30 минут** с пушем доверенному человеку (внуку) или **остановить**, если получатель уже в базе мошенников. Каждое решение объяснено человеческим языком.

## Быстрый старт

```bash
cp .env.example .env          # по желанию: ANTHROPIC_API_KEY, TELEGRAM_BOT_TOKEN
docker compose up --build
```

| Что | Адрес |
|---|---|
| Сцена для питча (бабушка + внук + пульт) | http://localhost:5173/stage |
| Консоль антифрода (переводы, реестр, граф, OSINT) | http://localhost:5173/console |
| Апа.AI: сыграть мошенника | http://localhost:5173/apa |
| Приложение банка / телефон внука на реальных телефонах | http://IP-ноутбука:5173/bank и /guardian |
| API + Swagger | http://localhost:8000/docs |

Telegram-бот: `TELEGRAM_BOT_TOKEN=... docker compose --profile telegram up --build`.

### Без Docker (разработка)

```bash
cd api && pip install -r requirements-dev.txt && uvicorn qorgan.main:app --reload   # SQLite по умолчанию
cd web && npm install && npm run dev
cd bot && pip install -r requirements.txt && TELEGRAM_BOT_TOKEN=... python bot.py
cd api && pytest                                                                     # 11 тестов
```

## Ключевые решения

- **Приватность по умолчанию.** Номера карт и телефонов хранятся только как HMAC-SHA256 с секретом (`QORGAN_PEPPER`) и маской `440043******3417`. Совпадения ищутся по хэшу. От звонка берутся только метаданные, никакого аудио.
- **«Остановлено, связан с мошенниками» говорим только при доказательстве из реестра.** Поведенческий скор сам по себе максимум задерживает перевод. Доверенное лицо не может разрешить перевод на карту из реестра: только проверка банком.
- **Объяснимость.** Каждый вклад признака (коэффициент × стандартизированное значение) превращается в причину на русском: клиент, внук и аналитик видят одно и то же «почему».
- **Демо не зависит от интернета.** Без ключа Claude Апа работает на скриптовом движке; без сети OSINT делает лексический анализ. Регулярки + Луна + mod-97 извлекают улики всегда, LLM только добавляет к ним (и только то, что буквально есть в тексте мошенника).

## Честно о границах MVP

- **Модель обучена на синтетике**, которая кодирует известные паттерны APP-мошенничества (`api/qorgan/risk/model.py`). На пилоте переобучается на размеченных переводах банка (`RiskModel.train`). Цифры точности до пилота не заявляем.
- **Сигнал оператора** в демо подаётся с пульта. В пилоте это интеграция с оператором (по модели CAMARA / GSMA Open Gateway).
- **Апа в Telegram-боте** работает в чате с ботом (режим для демо и ред-тиминга). В продакшене Апа сидит на номерах-ловушках через userbot-аккаунты, по договору с банком / АФР.
- **Шина событий** в памяти одного процесса. Для нескольких инстансов заменить на Redis/NATS.
- Ключ API в веб-демо виден в браузере. В продакшене банк вызывает Qorgan со своего бэкенда.

## API за 30 секунд

```bash
H='X-API-Key: dev-bank-key'
# начался звонок
curl -s -XPOST localhost:8000/v1/signals/call -H "$H" -H 'content-type: application/json' \
  -d '{"customer_id":"cus_demo_bibigul","channel":"whatsapp","counterparty":"+77075550199","in_contacts":false}'
# проверка перевода
curl -s -XPOST localhost:8000/v1/transfers/score -H "$H" -H 'content-type: application/json' \
  -d '{"customer_id":"cus_demo_bibigul","amount":800000,"recipient":{"kind":"card","value":"4400431234123417"},
       "behavior":{"max_pause_ms":12000,"pasted_recipient":true,"app_switches":3}}'
```

Ключи по ролям: `admin`, `bank`, `bot` (переменная `QORGAN_API_KEYS`).
