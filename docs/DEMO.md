# Сценарий демо: 3 минуты

**Подготовка (за 10 минут до выхода):** `docker compose up --build`, открыть `/stage` на проекторе, нажать «Сбросить демо». На втором ноутбуке или телефоне открыть `/apa`. Включить звук на ноутбуке (у «внука» звучит пуш). Проверить, что в углу пульта горит `● live`.

## Ответы на вопросы жюри (готовые)

- **«А если звонок через WhatsApp, оператор же не видит?»** Поэтому сигнал два: оператор для сотовой связи и SDK в приложении банка. iOS `CXCallObserver` видит звонки WhatsApp/Telegram через CallKit, Android видит режим аудио `MODE_IN_COMMUNICATION`. Код в `sdk/`.
- **«Перевод после звонка?»** Учитываем звонки за последние 3 часа с затуханием: перевод через 10 минут после 40-минутного разговора с незнакомцем всё равно рискованный.
- **«Ложные срабатывания?»** Один сигнал никогда не блокирует. Звонок с незнакомцем + перевод на 10 000 своим = пропуск. Мягкая лестница: вопрос → пауза → блок только при доказательстве из реестра.
- **«Приватность?»** Только метаданные звонка, никакого аудио. Карты и телефоны хранятся как HMAC-хэш. Работа по согласию клиента в приложении.
- **«Почему Kaspi не сделает сам?»** Может. Но звонок видит оператор, а мошеннические карты нужны из всех банков. Qorgan нейтральная платформа между операторами и банками №2–10, которым не по силам строить своё.
- **«Модель на чём обучена?»** Честно: стартовая модель на синтетике по известным паттернам, логистическая регрессия ради объяснимости. На пилоте переобучаем на данных банка.
- **«Апу раскусят?»** Может быть, через 5–10 минут. Но карту дропа мошенник называет раньше, иначе не получит денег. Наша метрика не «обмануть навсегда», а «хотя бы одна улика за разговор».
