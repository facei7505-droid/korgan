# Qorgan как продукт

## Что продаём

| Модуль | Кому | Что даёт |
|---|---|---|
| **Qorgan Risk API** | Банки, МФО, платёжные сервисы | Риск-скор перевода за десятки миллисекунд с причинами. Пауза, вопрос, доверенное лицо, блок |
| **Qorgan Mobile SDK** | Банки (в своё приложение) | Детект активного звонка, включая мессенджеры, и поведенческие сигналы при переводе |
| **Qorgan Guardian** | Клиенты банка (через банк) | Доверенный человек получает пуш/Telegram и может остановить перевод близкого |
| **Apa.AI Intel Feed** | Банки, АФР, KZ-CERT, операторы | Поток свежих карт дропов, номеров, фишинговых доменов и сценариев до первых жертв |
| **Telco Signal Gateway** | Операторы связи | Новый доход: продажа сигнала «клиент сейчас на подозрительном звонке» банкам по API |

## Модель денег (предложение для пилота)

- Банк: фикс за подключение + плата за каждую проверку перевода (дешевле, чем возмещение одного случая мошенничества).
- Оператор: доля от каждого запроса сигнала звонка.
- Intel Feed: подписка для банков и госорганов.

## Почему сейчас

- Мировой тренд: банк отвечает за APP-мошенничество. Великобритания ввела обязательное возмещение жертвам с октября 2024, Сингапур ввёл Shared Responsibility Framework. Когда платит банк, защита окупается сразу.
- Операторы по всему миру уже продают банкам сигналы через API (GSMA Open Gateway / CAMARA, например проверка замены SIM). «Подозрительный звонок прямо сейчас» это следующий, более ценный сигнал.
- Индия запустила национальный ИИ против дроп-счетов (MuleHunter.AI). Значит регуляторы готовы к таким системам.

## Конкуренты и отличие

- BioCatch, Feedzai и аналоги: сильная поведенческая аналитика, но без сигнала оператора и без данных о местных дропах.
- Google на Android детектирует мошеннические звонки, но не видит банковских переводов.
- Собственный антифрод банка не видит звонков и карт мошенников из других банков.
- **Qorgan соединяет звонок + поведение + разведку Апы** и знает казахский язык и местные схемы.

## План пилота (8–12 недель)

1. Один банк (не №1 по рынку), только SDK в приложении + Risk API. Без оператора.
2. Теневой режим 4 недели: скорим, но не блокируем, сравниваем с жалобами.
3. Включаем вопрос и паузу для клиентов 60+ и переводов новым получателям.
4. Подключаем Apa.AI Intel Feed и одного оператора.
Метрики: доля предотвращённых случаев, ложные срабатывания на 1000 переводов, время до первой улики Апы.

## Юридическое (проверить с юристом до пилота)

- Согласие клиента на обработку метаданных звонков в приложении банка.
- Сигнал оператора без содержания разговора; требования к тайне связи и персональным данным РК.
- Апа на номерах-ловушках по договору с банком / АФР, без «встречного взлома». OSINT только из открытых источников.
